# .trae 目录说明

本目录包含用于辅助 AI 助手进行项目开发的所有配置文件和文档。

## 文件清单

### 📋 核心配置文件

#### 1. [`project-rules.md`](./project-rules.md) - 项目开发规范
**用途**: 定义项目的开发规范、代码风格、架构约定
**内容**:
- 项目技术栈说明
- Python 编码规范
- 模块架构约定
- AI 协作约定
- 开发工作流
- 常用命令

**何时使用**: 
- 开始开发前阅读，了解项目规范
- 不确定代码风格时查阅
- 新增模块时参考架构约定

#### 2. [`ai-assistant-guide.md`](./ai-assistant-guide.md) - AI 助手开发指南
**用途**: 帮助 AI 助手快速理解项目，更好地辅助开发
**内容**:
- 项目核心功能说明
- 技术架构详解
- 开发优先级
- 代码开发指南
- 常见问题解答
- 快速参考

**何时使用**:
- AI 助手首次接触项目时
- 需要 AI 协助开发功能时
- 遇到技术问题时

### 📝 任务管理文件

#### 3. [`task-checklist.md`](./task-checklist.md) - 开发任务清单
**用途**: 跟踪开发进度，管理待办任务
**内容**:
- 待开发功能清单（按优先级）
- 测试任务清单
- 文档任务清单
- Sprint 进度跟踪
- 任务分配建议

**何时使用**:
- 选择开发任务时
- 更新开发进度时
- 分配任务给团队成员时

#### 4. [`quick-reference.md`](./quick-reference.md) - 快速参考手册
**用途**: 提供常用命令、代码片段、数据结构速查
**内容**:
- 常用命令速查
- 模块导入速查
- 配置项速查
- 日志记录速查
- 数据类型速查
- 数据库操作速查
- 常见错误处理
- 调试技巧

**何时使用**:
- 忘记命令语法时
- 需要快速查找代码示例时
- 调试程序时

## 使用流程

### 新成员入职流程

1. **阅读项目规范**
   ```bash
   # 阅读 .trae/project-rules.md
   # 了解编码规范和架构约定
   ```

2. **了解开发指南**
   ```bash
   # 阅读 .trae/ai-assistant-guide.md
   # 理解项目架构和开发优先级
   ```

3. **选择开发任务**
   ```bash
   # 查看 .trae/task-checklist.md
   # 选择 P0 优先级的任务开始开发
   ```

4. **参考快速手册**
   ```bash
   # 开发过程中查阅 .trae/quick-reference.md
   # 查找命令示例和代码片段
   ```

### AI 助手协作流程

1. **理解需求**
   - AI 阅读 `project-rules.md` 了解规范
   - AI 阅读 `ai-assistant-guide.md` 理解架构

2. **选择任务**
   - 查看 `task-checklist.md` 确定优先级
   - 选择待开发的 TODO 功能

3. **实现功能**
   - 参考 `quick-reference.md` 中的代码示例
   - 遵循 `project-rules.md` 中的编码规范

4. **测试验证**
   - 编写单元测试
   - 运行测试命令
   - 更新任务清单

## 与其他文档的关系

### .trae/ vs README.md
- **README.md**: 项目总体介绍，面向所有读者
- **.trae/**: 开发详细指南，面向开发者和 AI 助手

### .trae/ vs DEVELOPMENT_TASKS.md
- **DEVELOPMENT_TASKS.md**: 详细的模块任务分配
- **.trae/task-checklist.md**: 简明的任务清单和进度跟踪

### .trae/ vs 代码注释
- **代码注释**: 解释具体实现细节
- **.trae/文档**: 提供整体开发指导和规范

## 贡献指南
